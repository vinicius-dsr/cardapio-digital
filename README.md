# Cardapio Digital

Este é um cardápio digital desenvolvido utilizando HTML, Tailwind CSS e JavaScript. Com ele, você pode adicionar produtos ao carrinho e realizar pedidos diretamente pelo WhatsApp.

## Funcionalidades

* Adição de produtos ao carrinho
* Realização de pedidos pelo WhatsApp
* Interface fácil de usar

## Tecnologias Utilizadas

* HTML
* Tailwind CSS
* JavaScript
